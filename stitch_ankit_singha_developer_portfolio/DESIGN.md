## Brand & Style

This design system embodies a cinematic, hyper-focused aesthetic that marries advanced artificial intelligence engineering with refined architectural minimalism. Designed for high-impact developer presentation, it projects technical supremacy, deliberate craftsmanship, and deep systems intelligence without visual clutter.

### Aesthetic Pillars
- **Cinematic Void**: Vast, controlled negative space built on obsidian and slate depths, evoking deep-space command centers and high-end compute clusters.
- **Selective Luminescence**: Electric hyper-accents deployed with mathematical discipline—never decorative washes, always purposeful signifiers of active execution, status, and focus.
- **Engineered Precision**: Hairline structural grids, razor-sharp typographic scale, and monospaced telemetry that immediately communicate engineering rigor and senior-level architectural thinking.
- **Glassmorphic Substrate**: Multi-layered dark glass surfaces with faint refraction, offering structural depth while retaining an ultra-clean, modern profile.

## Colors

The palette is anchored in absolute and near-black tones, allowing optical accents to radiate with controlled energy. Contrast ratios rigorously exceed WCAG AAA standards for text readability over deep surfaces.

### Surface Architecture
- **Base Canvas (`#08090D`)**: Deep void base layer. Absorbs light; provides extreme contrast.
- **Surface Level 1 (`#101218`)**: Primary containers, background cards, and docked panels.
- **Surface Level 2 (`#141720`)**: Elevated cards, dropdown overlays, active state modules.
- **Surface Level 3 (`#1D2230`)**: Hover target states, popovers, and interactive chips.

### Functional Accents
- **Primary (`#4F8CFF`)**: Electric Cobalt. Designates primary actions, live terminal cursors, high-priority links, and core metrics.
- **Secondary (`#8B5CF6`)**: Luminous Violet. Used for AI/ML inference tags, predictive UI paths, and secondary gradient junctions.
- **Tertiary (`#06D6A0`)**: Quantum Cyan/Mint. Applied strictly to real-time status indicators, production deployment badges, and uptime metrics.

### Monochrome & Transparency Spectrum
- **Text Primary (`#F3F5F9`)**: 95% opacity off-white for zero-fatigue high-contrast reading.
- **Text Secondary (`#94A3B8`)**: Cool slate for metadata, supporting technical summaries, and inactive states.
- **Border Subtle (`rgba(255, 255, 255, 0.08)`)**: Hairline delineation across all component envelopes.
- **Border Focus (`rgba(79, 140, 255, 0.40)`)**: Interactive field activation state.

## Typography

The typographic hierarchy establishes clear structural authority. **Space Grotesk** lends structural futurism and geometric edge to all editorial headings. **Inter** ensures effortless legibility for long-form case studies, architecture breakdowns, and descriptive project copy. **JetBrains Mono** anchors technical credibility across metrics, code snippets, execution badges, and telemetry outputs.

### Typographic Rules
- Headings maintain a slightly tightened tracking (`-0.02em` to `-0.03em`) to enhance cohesion.
- `terminal-tag` labels must always render in uppercase with `+0.08em` tracking.
- Code blocks must prioritize standard ligature support and high vertical rhythm to mimic IDE environments.

## Layout & Spacing

The layout is built upon an adaptive 12-column fluid grid system bounded by a max-width of `1440px` to maintain cinematic proportions on ultra-wide screens.

### Grid Breakpoints
- **Mobile (< 768px)**: 4 columns, `margin-mobile` (1.25rem), `gutter-sm` (1rem). Navigation collapses to an integrated bottom glass HUD dock.
- **Tablet (768px - 1024px)**: 8 columns, `margin` (2rem), `gutter` (1.5rem).
- **Desktop (> 1024px)**: 12 columns, `margin` (3rem), `gutter` (1.5rem).

### Vertical Rhythm
Section blocks adhere to an expansive rhythm using `space-2xl` and `space-3xl`, creating the deliberate, atmospheric pacing of high-end editorial portfolios. Component interiors use strict multiples of 4px/8px, prioritizing compact density for technical telemetry and generous breathing room for architectural project showcases.

## Elevation & Depth

Depth is generated through optical transparency, ambient backlight diffraction, and subtle boundary containment rather than traditional high-opacity drop shadows.

### Elevation Tiers
- **Tier 0 (Canvas)**: Non-reflective matte `#08090D`.
- **Tier 1 (Base Panels & Rail)**: Background `rgba(16, 18, 24, 0.75)`, backdrop blur `16px`, hairline border `1px solid rgba(255, 255, 255, 0.08)`.
- **Tier 2 (Interactive Modules & Project Cards)**: Background `rgba(20, 23, 32, 0.85)`, backdrop blur `24px`, shadow `0 12px 32px -8px rgba(0, 0, 0, 0.6)`. Hairline border dynamic on hover.
- **Tier 3 (Floating HUD, Drawers & Modals)**: Background `rgba(29, 34, 48, 0.90)`, backdrop blur `32px`, border `1px solid rgba(255, 255, 255, 0.14)`, shadow `0 24px 64px -12px rgba(0, 0, 0, 0.85)`.

### Chromatic Mesh Glows
Accent lights are created via localized radial gradients behind critical anchors:
- Primary Aura: `radial-gradient(circle at top left, rgba(79, 140, 255, 0.12), transparent 70%)`
- Intelligence Aura: `radial-gradient(circle at center, rgba(139, 92, 246, 0.08), transparent 60%)`

## Shapes

The geometric architecture avoids bubbly or organic rounding in favor of crisp, engineered corners that reflect technological discipline. 

- **Containers & Project Cards**: Base radius of `0.5rem` (`rounded-lg`), delivering a chiseled modern appearance without industrial harshness.
- **Interactive Controls (Buttons, Inputs)**: `0.375rem` (`rounded-md`) for tactical, tool-like affordance.
- **Micro-Chips, Status Indicators & Badges**: Fully pill-shaped (`rounded-full` / `9999px`) to create clear semantic contrast against structural, rectilinear containers.

## Components

### Buttons
- **Primary (Action)**: Solid fill of electric cobalt (`#4F8CFF`), high-contrast dark text (`#08090D`), font weight 600. Subtle external glow on hover: `box-shadow: 0 0 20px rgba(79, 140, 255, 0.35)`.
- **Secondary (Technical Outline)**: Dark glass fill (`rgba(255, 255, 255, 0.03)`), border `1px solid rgba(255, 255, 255, 0.12)`, text `#F3F5F9`. Hover state shifts border to `rgba(79, 140, 255, 0.5)` and illuminates background to `rgba(79, 140, 255, 0.06)`.
- **Ghost Monospace**: Transparent background, text `#94A3B8`, font family `JetBrains Mono`. Underlines with primary color on hover.

### Cards & Project Showcases
- Enclosed within Tier 1 glass. 1px hairline border `rgba(255, 255, 255, 0.08)`.
- **Interactive Transition**: On pointer hover, the outer border transitions smoothly to a gradient blend of `#4F8CFF` and `#8B5CF6` at 35% opacity, and the card subtly translates -2px vertically.

### Chips & Telemetry Tags
- Compact height (`24px`), `rounded-full`, font `JetBrains Mono` at `11px`.
- Status Chip: Live green pulse ring (`#06D6A0`) coupled with `rgba(6, 214, 160, 0.1)` surface.
- Technology Pill: Neutral surface (`rgba(255, 255, 255, 0.04)`), hairline border `rgba(255, 255, 255, 0.08)`, text `#94A3B8`.

### Input Fields & Terminal Consoles
- Surface background `#0B0D12`. Inset border `1px solid rgba(255, 255, 255, 0.1)`.
- Font: `Inter` for standard forms, `JetBrains Mono` for command/search prompts.
- Focus State: Outer boundary glows with `0 0 0 1px #4F8CFF`, border transitions to `#4F8CFF`.

### Terminal & Code Enclosures
- Top bar with mac-style indicator dots dimmed to monochrome low-opacity.
- Header displays route or file path (`ankit@core:~/architecture/distributed-systems`).
- Line numbers in `#94A3B8` at 40% opacity; code tokens cleanly highlighted with custom electric blue, violet, and mint palettes.
